# Scaling Thoughts: At $125 a Month, Can Productivity Scale with Token Usage?

> Originally published on [Zhihu Pin](https://www.zhihu.com/pin/1994893951887495269), 2026-01-14

For the first time, I subscribed to an Ultra/Max tier AI service. Claude Max 5x, paid via the Apple Store, at 125 USD per month.

Previously, I had been using Codex / Claude Code / Cursor together. However, I found that my main driver was still Claude Code. Codex produces good results, but the wait is too long. Cursor gets routed once you burn through the 20 USD quota, and I feel it is better suited for when I am fine-tuning a project. Claude Code with Opus 4.5 combines both quality and speed for a very smooth experience; the only downside is that the Pro tier usage limit is too low.

After waiting out the 5-hour limit twice, I decided to subscribe to Max for a while to see if my efficiency can scale further as my token usage scales. (This was a view I formed a while back, during a period when I was heavily using AI for self-reflection, project management, and fitness/diet/investment management.) Plus, it coincided with the release of Claude Cowork, so I get to try that out as well.
